# ChirpSmith rack fonts

These are the unmodified Latin WOFF2 files served by Google Fonts. The board serves both files from its loopback origin.

- [Saira Stencil One](https://github.com/google/fonts/tree/main/ofl/sairastencilone), regular, Google Fonts v19. [SIL OFL 1.1](Saira-Stencil-One-OFL.txt)
- [Chakra Petch](https://github.com/google/fonts/tree/main/ofl/chakrapetch), semibold, Google Fonts v13. [SIL OFL 1.1](Chakra-Petch-OFL.txt)
